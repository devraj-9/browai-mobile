# CURV AI Terminal - Mobile Trading & Intelligence Copilot

A high-performance, responsive React Native (Expo) mobile trading application built for institutional-grade asset analysis, paper trading, and real-time AI copilot assistance.

## 🚀 Key Features

- **Authenticated Experience**: Complete Sign In / Sign Up flow with **One-Click Instant Demo Access** for rapid evaluator review.
- **Interactive Multi-Asset Terminal**: Real-time market tracking across Stocks, Crypto, and Forex with dynamic timeframe analysis (1D, 1W, 1M, 1Y, ALL) and responsive trend charts.
- **AI Copilot Neural Chat**: Natural language AI market assistant providing technical entry/exit rationale, RSI insights, and resistance target levels.
- **Multi-Category Watchlist & Screener**: Live ticker management with category filtering (Stocks, Crypto, Forex) and custom asset dynamic addition.
- **Paper Trading Engine**: Real-time Order Depth (DOM) inspection with interactive BUY/SELL execution modals and live P&L tracking in the Portfolio tab.
- **Mobile Ergonomics Optimization**: Custom bottom-inset padding tailored for Android gesture & navigation bar compatibility (tested on Xiaomi/MIUI environments).

## 🛠️ Tech Stack

- **Framework**: React Native (Expo SDK)
- **Language**: TypeScript
- **Icons**: Lucide Icons React Native
- **Build Tool**: EAS (Expo Application Services)
